# ES4A

[ES4A](https://es4a.wsd.cx) 是面向 [Simple](https://code.google.com/archive/p/simple/) 中文编程语言的集成开发环境，当前以 Visual Studio Code 扩展形式提供。

Simple 采用类似 BASIC 的中文语法，面向 Android 应用开发。ES4A 集成项目管理、代码编辑、语言智能、窗口设计、资源管理及编译调试等能力，帮助具备基础编程知识的用户轻松上手 Android 应用开发。


## 主要功能

- Simple 语法着色
- 代码提示、自动补全与参数提示
- 悬停信息、文档注释与转到定义
- 项目、单元及资源管理
- SDK 类库浏览与导航
- Android `res` 资源索引
- 可视化窗口布局设计
- 应用编译与一键调试
- 等等...


## 快速上手

- [下载SDK](https://dwz.wsd.cx/es4a-xz)，解压到目录
- 安装启用扩展，选择SDK清单
- 主侧边栏切换ES4A标签页，创建或选择项目
- 开整...按F5调试...

> 推荐安装个自己喜欢的 `logcat` 扩展，方便审查调试输出
